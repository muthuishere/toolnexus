---
title: Install — all seven languages
description: Install toolnexus in JavaScript, Python, Go, Java, C#, Elixir or Clojure. Same behavior, native shape.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

The six shipped ports are published from the same release and carry the same version. The seventh —
Clojure — is a single `.cljc` source tree (JVM + [cljgo](https://github.com/muthuishere/cljgo)) with
[koine](https://github.com/muthuishere/koine) as its only dependency, and it is **not published yet**.

<Tabs syncKey="lang">
<TabItem label="JavaScript">
```sh
npm install toolnexus
```
[npm · toolnexus](https://www.npmjs.com/package/toolnexus) · MCP SDK: `@modelcontextprotocol/sdk`
</TabItem>
<TabItem label="Python">
```sh
pip install toolnexus
```
Python ≥ 3.11 · [PyPI · toolnexus](https://pypi.org/project/toolnexus/) · MCP SDK: `mcp`
</TabItem>
<TabItem label="Go">
```sh
go get github.com/muthuishere/toolnexus/golang
```
Go 1.23 · also ships the `toolnexus` CLI · MCP SDK: `mark3labs/mcp-go`
</TabItem>
<TabItem label="Java">
```xml
<dependency>
  <groupId>io.github.muthuishere</groupId>
  <artifactId>toolnexus</artifactId>
  <version>0.11.0</version>
</dependency>
```
Java 21 · [Maven Central](https://central.sonatype.com/artifact/io.github.muthuishere/toolnexus) · MCP SDK: `io.modelcontextprotocol.sdk:mcp`
</TabItem>
<TabItem label="C#">
```sh
dotnet add package Toolnexus
```
[NuGet · Toolnexus](https://www.nuget.org/packages/Toolnexus) · MCP SDK: `ModelContextProtocol`
</TabItem>
<TabItem label="Elixir">
```elixir
# mix.exs
def deps do
  [{:toolnexus, "~> 0.11"}]
end
```
Elixir ≥ 1.16 / OTP 26 · [Hex · toolnexus](https://hex.pm/packages/toolnexus) · MCP client: in-house (OTP-supervised, no SDK)
</TabItem>
<TabItem label="Clojure">
**Not yet released to Clojars.** There is no `net.clojars.muthuishere/toolnexus` artifact to depend
on — use the port from a checkout of the repo (its `clojure/` directory is a normal deps.edn
project), or build and install it locally with `clojure -T:build install`:

```clojure
;; deps.edn — point at a checkout; koine is the only third-party dependency
{:deps {net.clojars.muthuishere/koine {:mvn/version "0.9.1"}}
 :paths ["src" "../toolnexus/clojure/src"]}
```
Clojure CLI (JVM) or [cljgo](https://github.com/muthuishere/cljgo) · MCP client: in-house over
[koine](https://github.com/muthuishere/koine) (`koine.process` stdio / `koine.http` streamable-HTTP)
· [API reference](/toolnexus/api/clojure/)
</TabItem>
</Tabs>

Once installed, head to the [Quickstart](/toolnexus/quickstart/).
