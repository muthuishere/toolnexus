## Point it at your tools. Get a working agent.

Point Toolnexus at an `mcp.json` and a `skills/` folder and you get the tool-calling loop,
skills injection, six unified tool sources, and conversation memory — all included.
The same three lines, in every language:

<Tabs syncKey="lang">
<TabItem label="JavaScript">
```ts
import { createToolkit, createClient } from "toolnexus"

const tk = await createToolkit({
  mcpConfig: "./mcp.json",                           // every MCP server's tools
  skillsDir: "./skills",                             // every SKILL.md, loaded on demand
})
const agent = createClient({
  baseUrl: "https://openrouter.ai/api/v1",          // any OpenAI- or Anthropic-style endpoint
  style: "openai",
  model: "openai/gpt-4o-mini",
})

const { text } = await agent.run("Use my tools to answer this.", { toolkit: tk })
console.log(text)
```
</TabItem>

<TabItem label="Go">
```go
package main

import (
	"context"
	"fmt"

	"github.com/muthuishere/toolnexus/golang"
)

func main() {
	ctx := context.Background()
	tk, _ := toolnexus.CreateToolkit(ctx, toolnexus.Options{
		MCPConfig: "./mcp.json", // every MCP server's tools
		SkillsDir: "./skills",   // every SKILL.md, loaded on demand
	})
	defer tk.Close()

	agent := toolnexus.CreateClient(toolnexus.ClientOptions{
		BaseURL: "https://openrouter.ai/api/v1",
		Style:   "openai",
		Model:   "openai/gpt-4o-mini",
	})

	res, _ := agent.Run(ctx, "Use my tools to answer this.", tk)
	fmt.Println(res.Text)
}
```

<TabItem label="Rust">
```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{McpConfigInput, ToolkitOptions, create_toolkit};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let tk = create_toolkit(ToolkitOptions {
        mcp_config: Some(McpConfigInput::Path("./mcp.json".into())), // every MCP server's tools
        skills_dir: vec!["./skills".into()],                         // every SKILL.md, loaded on demand
        ..Default::default()
    })
    .await?;

    let agent = create_client(ClientOptions {
        base_url: "https://openrouter.ai/api/v1".into(),
        style: Style::OpenAI,
        model: "openai/gpt-4o-mini".into(),
        ..Default::default()
    });

    let res = agent.run("Use my tools to answer this.", &tk).await?;
    println!("{}", res.text);
    tk.close().await;
    Ok(())
}
```

## One interface for every tool

<CardGrid>
	<Card title="MCP servers" icon="puzzle">
		Read an `mcp.json`, connect to every server (local stdio + remote streamable-HTTP),
		expose each server tool as a uniform `Tool`.
	</Card>
	<Card title="Agent skills" icon="open-book">
		Glob a `skills/` folder of `SKILL.md` files; one `skill` tool loads instructions and
		resources on demand — progressive disclosure.
	</Card>
	<Card title="Your own functions" icon="setting">
		Register a plain function as a tool. Native, HTTP endpoints, and the built-in shell/file
		tools all share the same shape.
	</Card>
	<Card title="Remote A2A agents" icon="rocket">
		Another agent, called like a function. `toolkit.serve(...)` also exposes *your* toolkit
		to the world as an A2A agent.
	</Card>
	<Card title="The loop, included" icon="approve-check">
		System prompt, skills injection, parallel + chained tool calls, hooks, streaming, retries,
		conversation memory, observability metrics.
	</Card>
	<Card title="Human in the loop" icon="comment">
		The suspension layer: an agent can pause, ask *you* a question, and resume — plus an
		MCP elicitation bridge. Nobody else ships this across eight ports.
	</Card>
	<Card title="Typed decisions" icon="list-format">

## Byte-identical across eight languages

The whole point is **parity**: the same `examples/` fixtures produce the same behavior in every
language — all seven published to their registries. [Clojure](/toolnexus/api/clojure/) is one
`.cljc` tree that runs on the JVM and on cljgo, wired into the same conformance checker at the
same **full** tier, agent layer included.
Install for yours on the [install page](/toolnexus/install/), or start with the
[quickstart](/toolnexus/quickstart/).
