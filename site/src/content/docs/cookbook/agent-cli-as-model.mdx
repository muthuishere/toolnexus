<Aside type="tip" title="Why you need this">
You already pay for a coding-agent subscription. `createCliClient` makes that CLI the model behind an
ordinary toolnexus client — system prompt, skills, memory, hooks and metrics as usual — and your
toolkit (MCP servers, skills, native tools) is what it calls. toolnexus never picks or ships the
binary: `command` is required and the CLI runs under your own login.
</Aside>

## How it reaches the agent

- **`style`** is an enum (`CliStyles.Claude | Codex | Copilot | Opencode | Devin | Gemini | Goose | Custom`),
  never a string. Styles are shared data in `conformance/cli-styles/`, each with the CLI version it was
  verified against.
- **ACP first** (`transport` Auto): when the style has an ACP launch and the binary answers `initialize`,
  your toolkit is served on `127.0.0.1/mcp` behind a per-session bearer token and handed to the agent in
  `session/new`. The agent calls your tools natively; `skill` is served as `load_skill`; only your tools
  are permitted, the agent's own shell/edit/fetch are rejected. Hooks run at the server boundary.
  claude needs an adapter as `acpCommand` (`npx -y @agentclientprotocol/claude-agent-acp@0.100.0`).
  devin's style adds a system hint naming the `toolnexus` MCP server so it finds the tools.
- **One-shot fallback**: a CLI without ACP (codex) or whose ACP launch fails is run once per turn with
  the conversation in a JSON envelope; tool calls come back to the toolnexus loop.
- Default per-call timeout 300 s; pinned errors (`cli: command not found: …`, `cli: exit <code>: …`,
  `cli: timed out after <ms>ms`, `cli: empty reply`, `cli: no output file`); `usage` is zero.
- **Streaming** works everywhere but is non-incremental: tool events, the whole answer as one text chunk, then done.

<Aside type="caution" title="Port gaps">
Streaming never errors: every style and transport yields the tool events, then the whole answer as one chunk, then done (Go's ACP transport streams incrementally). Java, C#, Elixir and Clojure kill the process tree
instead of a process group. Rust needs the `serve` feature for ACP. goose and gemini's one-shot mode are
marked UNVERIFIED. Contract: SPEC §8C, ADR 0037.
</Aside>
