<Aside type="tip" title="Why you need this">
Every media provider makes you write a start request, a polling loop, a hunt through the response
for the file, and a download before the URL expires, and then do it again when the provider runs
out of credits. With toolnexus you hand `createMedia` one **named media client** (or a CLI
preset) and call typed verbs; a client that cannot serve a call right now (no key, no credits, a
CLI that is missing or blocked) raises one typed `unavailable` error.
</Aside>

The concepts, the full client table and every config field are on the
[Media generation](/toolnexus/media/) page. Keys are read from each client's env var
(`OPENAI_API_KEY`, `FAL_API_KEY`, `ELEVENLABS_API_KEY`, `A2E_API_KEY`, `OPENROUTER_API_KEY`) when
a request is sent, and never logged. The CLI presets (`xai-grok-cli`, `openai-codex-cli`,
`google-agy-cli`) drive the vendor's official CLI in its documented headless mode, signed in by you;
your provider's terms of service apply to how you use its CLI. Setup:
[Grok CLI, Codex CLI and Antigravity media setup](/toolnexus/cookbook/cli-media-setup/).

## 1. Named clients

One client per media object. Video comes from the Grok CLI through the `xai-grok-cli` preset
(setup: [Grok CLI, Codex CLI and Antigravity media setup](/toolnexus/cookbook/cli-media-setup/));
images come from OpenAI. With `gather` mode `download`, every file is saved locally and you get a
`path`. If a client cannot serve the call right now (no key, no credits, a CLI that is missing,
blocked by [Zero Data Retention](/toolnexus/media/#grok-video-zdr) or at its usage limit), you get
the typed `unavailable` error.

## 2. The seven typed verbs

Image, then a video from that image, then speech, music, a transcript of the speech, and a
talking-head video from the face and the voice. Each provider gets its own media object: fal for
image and video, ElevenLabs for speech, music and transcribe, A2E for talk. Outputs chain as
inputs: a local `path`, a `file://` URL or an `http(s)` URL all work.

<Aside type="note">
ElevenLabs music and transcribe, fal video and A2E talk are implemented from the providers' docs
but have not had a live call yet (SPEC §7G.9). On Clojure, raw-byte results (ElevenLabs speech and
music) and uploads are not byte-exact yet; see the [guide](/toolnexus/media/).
</Aside>

```ts
const audio = voice.files[0].path ?? voice.files[0].url!
const words = await eleven.transcribe({ audio })
const talk = await a2e.talk({ image: face, audio })   // a2e needs image + audio
console.log(vid.status, tune.files.length, words.text, talk.files[0])
```

## 3. Your agent: the verbs as tools

Media tools are opt-in. Pass the media object to the toolkit and the agent gets `generate_image`,
`generate_video`, … for the verbs its client supports. Every file the agent makes lands in
`RunResult.files`, in call order, with `from` (the tool) and `callId`. Only **image** parts are
sent back to the model; video and audio stay out of its context, and it sees just the
`"video ready: <path>"` line.

<Tabs syncKey="lang">
<TabItem label="JavaScript">
```ts
import { createClient, createToolkit, createMedia, OpenAIMediaClient } from "toolnexus"

const media = createMedia(new OpenAIMediaClient())
const tk = await createToolkit({ media })          // adds generate_image, generate_speech, …
const agent = createClient({ baseUrl: "https://openrouter.ai/api/v1", style: "openai", model: "openai/gpt-4o-mini" })
const res = await agent.run("Draw a lighthouse at dusk, then animate it.", { toolkit: tk })
for (const f of res.files) console.log(f.from, f.mimeType, f.url ?? `(${f.data?.length} b64 chars)`)
```
</TabItem>

## 4. A custom MediaClient

Anything not built in is a small class (or map, or module) with a name, `supports`, and the verbs
it handles. Signal `unavailable` when it cannot serve a call right now (no key, no quota).

<Tabs syncKey="lang">
<TabItem label="JavaScript">
```ts
import { createMedia, MediaUnavailableError, type MediaClient, type MediaResult } from "toolnexus"

const placeholder: MediaClient = {
  name: "placeholder",
  supports: (verb) => verb === "image",
  async image(args): Promise<MediaResult> {
    if (!process.env.PLACEHOLDER_ON) throw new MediaUnavailableError("placeholder: switched off")
    const url = `https://placehold.co/600x400?text=${encodeURIComponent(String(args.prompt))}`
    return { files: [{ type: "image", mimeType: "image/png", url }], status: "completed" }
  },
}
const res = await createMedia(placeholder).image({ prompt: "hello" })
```
</TabItem>
<TabItem label="Python">
```python
import os
from urllib.parse import quote
from toolnexus import create_media, BaseMediaClient, MediaFile, MediaResult, MediaUnavailableError

class Placeholder(BaseMediaClient):
    name = "placeholder"

    def supports(self, verb): return verb == "image"

    async def generate(self, verb, args, ctx):
        if not os.environ.get("PLACEHOLDER_ON"):
            raise MediaUnavailableError("placeholder: switched off")
        url = f"https://placehold.co/600x400?text={quote(args['prompt'])}"
        return MediaResult(files=[MediaFile(type="image", mime_type="image/png", url=url)], status="completed")

res = await create_media(Placeholder()).image("hello")
```

```elixir
defmodule PicsumClient do
  @behaviour Toolnexus.Media.Client
  def name(_), do: "picsum"
  def supports?(_, verb), do: verb == "image"

  # Args arrive canonical and string-keyed. When it cannot serve a call, return:

  def image(_, args, _ctx) do

  end
end
```

```rust
use toolnexus::{MediaArgs, MediaClient, MediaCtx, MediaError, MediaFile, MediaFuture, MediaResult};

struct StockImages; // every verb it does not override fails

impl MediaClient for StockImages {
    fn name(&self) -> &str { "stock" }
    fn supports(&self, verb: &str) -> bool { verb == "image" }
    fn image<'a>(&'a self, args: MediaArgs, _ctx: &'a MediaCtx) -> MediaFuture<'a> {
        Box::pin(async move {
            if std::env::var("STOCK_OFFLINE").is_ok() {
                return Err(MediaError::unavailable("stock: offline")); // typed unavailable error
            }
            let q = args.get("prompt").and_then(|v| v.as_str()).unwrap_or_default().replace(' ', "+");
            let url = format!("https://images.example.com/search?q={q}");
            let file = MediaFile { kind: "image".into(), mime_type: "image/jpeg".into(), url, ..Default::default() };
            Ok(MediaResult { files: vec![file], status: "completed".into(), ..Default::default() })
        })
    }
}
```

## Show the files

`RunResult.files` and each `MediaResult.files` entry carry `type` and `mimeType`, so the host
decides how to show them: `<img>`, `<video controls>` or `<audio controls>` on the web; a media
message on WhatsApp, Telegram or Slack; a path on a CLI. With the default `gather` mode
`download` the files are already on disk, so expiring provider URLs are not a problem.
