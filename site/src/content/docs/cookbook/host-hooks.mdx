<Aside type="tip" title="Why you need this">
A host that puts an agent in front of a person — an IDE panel, a per-folder agent server, a
chat UI — needs more than a loop: ask before anything destructive runs, stop a pending
question when the user cancels, show tools as each MCP server comes up, say "context
compacted", and keep a subagent's `bash` behind the same gate as the parent's. 0.22.0 adds all
of it in all seven ports. Every addition is opt-in; unset, behaviour is unchanged.
</Aside>

## A permission gate from tool hints

Every tool now carries `hints = { readOnly, destructive, openWorld }` — set on every builtin,
read from MCP tool annotations, `nil`/absent when unknown (treat as mutating). They arrive on
the `beforeTool` event. There is no separate permit option; the gate *is* `beforeTool`:

- **allow** — return nothing;
- **deny** — return an error result (the model sees it, the run continues);
- **ask** — return `pending(request)`, which `waitFor` / `waitForCtx` resolves.

```js
const agent = createClient({
  baseUrl, style: "openai", model, apiKey,
  hooks: {
    beforeTool: (e) => {
      if (e.hints?.readOnly) return                       // let reads run
      return { result: pending({ kind: "input", prompt: `Run ${e.name}?` }) }  // ask
    },
  },
  waitFor: async (request, { signal }) => ui.ask(request, signal),  // ends with the turn
})
```

A call through `call_tool` (see [tool tiers](/cookbook/prompt-cache-and-tool-tiers/)) is
unwrapped before the hook, so the gate sees the real tool. Hints are advisory and never sent to
the model.

## Opt-in builtins

Off unless configured; the default ten builtins are unchanged.

| builtin | what it adds |
|---|---|
| `background` (a host-owned `BackgroundShells`) | `bash` gains `run_in_background`; `bash_output(id)` returns new output plus `[status: …]`; `kill_shell(id)` stops the process group. Call `closeAll` on shutdown |
| `webSearch` (a provider you supply; none ships) | `websearch` with numbered title / URL / snippet results |
| `notebookEdit` | `notebook_edit`: replace, insert or delete an `.ipynb` cell |
| `McpSource.resourceTools()` | `list_mcp_resources` / `read_mcp_resource`, read-only |

Also: `grep` takes `context` / `before` / `after`, and `read` / `grep` report a cut in metadata
(`truncated`, `nextOffset` / `total`) while the text stays the same bytes.

## By design, per port

- **Register mid-turn:** a tool added to a running toolkit is offered from the next model call
  (js, python, go, java, csharp). Elixir and Clojure toolkits are immutable values, so a running
  turn keeps the toolkit it started with.
- **Cancellation** is the turn context in Go, an abort signal in JS, a `CancelToken` / thread
  interrupt in Java, the turn's pid (`ctx.signal`) in Elixir, and a cooperative `:cancel` token
  in Clojure (checked between model calls and tool batches).
- **Background shells** are POSIX only in Clojure.
- **ACP host hooks** are Go only for now — see [ACP host hooks](/cookbook/acp-hooks/).
