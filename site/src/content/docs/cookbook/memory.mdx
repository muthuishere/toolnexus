<Aside type="tip" title="Why you need this">
A single `run` is stateless — it forgets everything the moment it returns. Real assistants
need continuity: remember who the user is, what was decided three turns ago, the context of
an ongoing task. Memory gives you multi-turn conversations keyed by id, with a pluggable
store so you can persist transcripts to Redis, Postgres, or anywhere your app already keeps state.
</Aside>

Keep a conversation across turns. JavaScript / Python / Go use a `conversation`
object whose `send` retains history; Java / C# / Elixir use `ask` with a stable id
whose transcript lives in the client's conversation store. Both remember turn 1 at
turn 2.

<TabItem label="JavaScript">
```js
const convo = agent.conversation({ toolkit: tk })
await convo.send("My name is Muthu. Remember it.")
const r = await convo.send("What's my name?")
console.log(r.text)   // recalls "Muthu"
```

<TabItem label="Rust">
```rust test
use std::sync::Arc;
use toolnexus::client::{GenerateFn, InProcessOptions, InProcessResponse, create_in_process_client};
use toolnexus::{BuiltinsConfig, ToolkitOptions, create_toolkit};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // A stand-in model that answers from the transcript it is sent.
    let generate: GenerateFn = Arc::new(|req| Box::pin(async move {
        let said = req.messages.iter().filter_map(|m| m["content"].as_str())
            .find_map(|c| c.strip_prefix("My name is ")).map(|n| n.trim_end_matches('.').to_string());
        Ok(InProcessResponse { content: format!("You are {}", said.unwrap_or("unknown".into())), ..Default::default() })
    }));
    let client = create_in_process_client(InProcessOptions { generate: Some(generate), ..Default::default() });
    let tk = create_toolkit(ToolkitOptions { builtins: Some(BuiltinsConfig::off()), ..Default::default() }).await?;

    client.ask("My name is Ada.", &tk, "user-42").await?;
    let again = client.ask("What is my name?", &tk, "user-42").await?; // same id => same transcript
    let other = client.ask("What is my name?", &tk, "user-7").await?;  // new id => fresh transcript
    assert_eq!(again.text, "You are Ada");
    assert_eq!(other.text, "You are unknown");
    // ClientOptions { store: Some(Arc::new(FileConversationStore::new("./convos")?)), .. } persists it
    println!("ok: {}", again.text);
    Ok(())
}
```
