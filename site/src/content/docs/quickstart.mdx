<Steps>

1. **Install the package.**

   <Tabs syncKey="lang">
   <TabItem label="JavaScript">
   ```sh
   npm install toolnexus
   ```
   </TabItem>
   <TabItem label="Python">
   ```sh
   pip install toolnexus
   ```
   </TabItem>
   <TabItem label="Go">
   ```sh
   go get github.com/muthuishere/toolnexus/golang
   ```
   </TabItem>
   <TabItem label="Java">
   ```xml
   <!-- Maven -->
   <dependency>
     <groupId>io.github.muthuishere</groupId>
     <artifactId>toolnexus</artifactId>
     <version>0.14.0</version>
   </dependency>
   ```
   </TabItem>
   <TabItem label="C#">
   ```sh
   dotnet add package Toolnexus
   ```
   </TabItem>
   <TabItem label="Elixir">
   ```elixir
   # mix.exs
   def deps do
     [{:toolnexus, "~> 0.14"}]
   end
   ```
   </TabItem>
   <TabItem label="Clojure">
   ```clojure
   ;; deps.edn — one artifact; koine (the portability seam) comes with it
   {:deps {net.clojars.muthuishere/toolnexus {:mvn/version "0.14.0"}}}
   ```
   </TabItem>
   </Tabs>

2. **Create a toolkit and a client.** The toolkit starts with 10 built-in tools
   (bash / read / write / edit / grep / glob / …). Point the client at any OpenAI- or
   Anthropic-style endpoint.

   <Tabs syncKey="lang">
   <TabItem label="JavaScript">
   ```ts
   import { createToolkit, createClient } from "toolnexus"

   const tk = await createToolkit()
   const agent = createClient({
     baseUrl: "https://openrouter.ai/api/v1",
     style: "openai",
     model: "openai/gpt-4o-mini",
   })
   ```
   </TabItem>
   <TabItem label="Python">
   ```python
   from toolnexus import create_toolkit, create_client

   tk = await create_toolkit()
   agent = create_client(
       base_url="https://openrouter.ai/api/v1", style="openai",
       model="deepseek/deepseek-chat",
   )
   ```
   </TabItem>
   <TabItem label="Go">
   ```go
   tk, _ := toolnexus.CreateToolkit(ctx, toolnexus.Options{})
   defer tk.Close()
   agent := toolnexus.CreateClient(toolnexus.ClientOptions{
       BaseURL: "https://openrouter.ai/api/v1",
       Style:   "openai",
       Model:   "openai/gpt-4o-mini",
   })
   ```
   </TabItem>
   <TabItem label="Java">
   ```java
   Toolkit tk = Toolkit.create(new Toolkit.Options());
   LlmClient agent = LlmClient.create(new LlmClient.Options()
           .baseUrl("https://openrouter.ai/api/v1")
           .style("openai")
           .model("openai/gpt-4o-mini"));
   ```
   </TabItem>
   <TabItem label="C#">
   ```csharp
   await using var tk = await Toolkit.CreateAsync(new Toolkit.Options());
   var agent = LlmClient.Create(new LlmClient.Options
   {
       BaseUrl = "https://openrouter.ai/api/v1",
       Style   = "openai",
       Model   = "anthropic/claude-3.5-sonnet",
   });
   ```
   </TabItem>
   <TabItem label="Elixir">
   ```elixir
   {:ok, tk} = Toolnexus.create_toolkit()
   agent =
     Toolnexus.Client.create(
       base_url: "https://openrouter.ai/api/v1",
       style: "openai",
       model: "openai/gpt-4o-mini"
     )
   ```
   </TabItem>
   <TabItem label="Clojure">
   ```clojure
   (require '[toolnexus.core :as tn] '[toolnexus.client :as client])

   (def tk (tn/build {:builtins true}))
   (def agent (client/create-client
                {:base-url "https://openrouter.ai/api/v1"
                 :style "openai"
                 :model "openai/gpt-4o-mini"}))
   ```
   </TabItem>
   </Tabs>

3. **Run.** Tools are called for you and the loop runs to a final answer.

   <Tabs syncKey="lang">
   <TabItem label="JavaScript">
   ```ts
   const { text } = await agent.run("What files are in this folder?", { toolkit: tk })
   console.log(text)
   ```
   </TabItem>
   <TabItem label="Python">
   ```python
   res = await agent.run("List the files here, then count them.", tk)
   print(res.text)
   ```
   </TabItem>
   <TabItem label="Go">
   ```go
   res, _ := agent.Run(ctx, "List the Go files here and count them.", tk)
   fmt.Println(res.Text)
   ```
   </TabItem>
   <TabItem label="Java">
   ```java
   System.out.println(agent.run("List the files here, then read the largest one.", tk).text);
   ```
   </TabItem>
   <TabItem label="C#">
   ```csharp
   var res = await agent.RunAsync("List the files here, then summarise the README.", tk);
   Console.WriteLine(res.Text);
   ```
   </TabItem>
   <TabItem label="Elixir">
   ```elixir
   res = Toolnexus.Client.run(agent, "List the files here, then count them.", tk)
   IO.puts(res.text)
   ```
   </TabItem>
   <TabItem label="Clojure">
   ```clojure
   (def res (client/run agent "List the files here, then count them." {:toolkit tk}))
   (println (:text res))
   ```
   </TabItem>
   </Tabs>

</Steps>

## Add MCP servers and agent skills

Give the toolkit an [`mcp.json`](/toolnexus/mcp/) and a [`skills/`](/toolnexus/skills/) folder and
every server tool + a `skill` tool appear in the same registry:

<Tabs syncKey="lang">
<TabItem label="JavaScript">
```ts
const tk = await createToolkit({
  mcpConfig: "./mcp.json",     // local stdio + remote streamable-HTTP servers
  skillsDir: "./skills",       // every SKILL.md becomes loadable via one `skill` tool
})
```
</TabItem>
<TabItem label="Python">
```python
tk = await create_toolkit(mcp_config="./mcp.json", skills_dir="./skills")
```
</TabItem>
<TabItem label="Go">
```go
tk, _ := toolnexus.CreateToolkit(ctx, toolnexus.Options{
    MCPConfig: "./mcp.json",
    SkillsDir: "./skills",
})
```
</TabItem>
<TabItem label="Java">
```java
Toolkit tk = Toolkit.create(new Toolkit.Options()
        .mcpConfig("./mcp.json").skillsDir("./skills"));
```
</TabItem>
<TabItem label="C#">
```csharp
await using var tk = await Toolkit.CreateAsync(new Toolkit.Options
{
    McpConfig = "./mcp.json",
    SkillsDir = "./skills",
});
```
</TabItem>
<TabItem label="Elixir">
```elixir
{:ok, tk} = Toolnexus.create_toolkit(mcp_config: "./mcp.json", skills_dir: "./skills")
```
</TabItem>
<TabItem label="Clojure">
```clojure
(def tk (tn/build {:mcp "./mcp.json" :skills "./skills"}))
```
</TabItem>
</Tabs>
