shown in eight-language synced tabs.

## Toolkit

- `Toolkit.CreateAsync(Toolkit.Options opts)`
- `Options`: `McpConfig`, `SkillsDir`, `Skills`, `SkillProvider`, `SkillsFilter`,
  `SkillSampleLimit`, `Builtins`, `Agents`, `ExtraTools`, `WaitFor` (plus `With…` fluent setters).
- Equivalents: `createToolkit` (js) · `create_toolkit` (py) · `CreateToolkit` (go) ·
  `Toolkit.create` (java) · `Toolnexus.create_toolkit` (elixir).

## Skills

- `SkillSource.Load(params string[] dirs)` — back-compat.
- `SkillSource.LoadWith(SkillSource.LoadOptions opts)`
- `SkillSource.ListSkills(LoadOptions opts) -> SkillInventory` — `.Skills`, `.Skipped`
  (`SkillSkip.Reason`; constants `SkillSkip.MissingName`, `Malformed`, `DuplicateName`,
  `Unreadable`).
- `record SkillDef(Name, Description, Content, Resources = null, Base = null)`
- `LoadOptions { Dirs, Skills, Filter, SampleLimit }`
- `SkillProvider` is a `Func<IEnumerable<SkillDef>>`.
- Equivalents: `loadSkills` / `listSkills` (js) · `load_skills` / `list_skills` (py) ·
  `LoadSkillsWith` / `ListSkills` (go) · `SkillSource.loadWith` / `listSkills` (java) · `Toolnexus.Skill.load` / `Toolnexus.Skill.list` (elixir).

## Tools you build — native, HTTP, built-ins

- `NativeTool.Of(name, description, schema, fn)` · `NativeTool.OfAsync(...)` — `(args,
  ToolContext)` overloads.
- `HttpTool.Of(HttpTool.Options)` — `{ Name, Description, Method, Url, Headers, Query, Body,
  ResultMode, Timeout }`; `Timeout` `long?` ms.
- `Builtins` toggle → ten built-ins: `bash · read · write · edit · grep · glob · webfetch ·
  question · apply_patch · todowrite`. (`BuiltinTools.Create()` / `.Select(cfg)`.)
- Equivalents: `defineTool` / `httpTool` (js) · `define_tool` / `http_tool` (py) · `NativeTool` /
  `HTTPTool` (go) · `NativeTool.of` / `HttpTool.of` (java) · `Toolnexus.Native.define_tool` /
  `Toolnexus.Http.tool` (elixir).

## Media generation

Guide: [Media generation](/toolnexus/media/) · recipe: [Generate images, video and speech](/toolnexus/cookbook/media/) · SPEC §7G.

- `MediaStyle.Load(string path)` · `MediaStyle.Parse(string json)` · `MediaStyle.FromDictionary(dict)`.
- `Media.Create(MediaStyle style, MediaOptions? options = null)` ·
  `Media.Create(IEnumerable<MediaStyle> styles, MediaOptions? options = null)` — a verb resolves to the
  first style that declares it.
- `MediaOptions { OnProgress: Action<MediaProgress>?, Progress: IProgress<MediaProgress>?, HttpClient: HttpClient?, HttpHandler: HttpMessageHandler? }`
  — `MediaProgress(Verb, JobId, Status)` after every poll.
- Verbs, each `Task<MediaResult> XAsync(XInput input, CancellationToken cancellationToken = default)`:
  `ImageAsync(new ImageInput(prompt) { Width, Height, AspectRatio, Seed, ProviderOptions })` ·
  `VideoAsync(new VideoInput(prompt) { Image, Seconds, AspectRatio, ProviderOptions })` ·
  `SpeechAsync(new SpeechInput(text) { Voice, ProviderOptions })` ·
  `TranscribeAsync(new TranscribeInput(audio) { ProviderOptions })` ·
  `CloneVoiceAsync(new CloneVoiceInput(name, samples) { ProviderOptions })` ·
  `TalkingAsync(new TalkingInput(image, audio) { ProviderOptions })`. `null` properties are not sent.
- `GenerateAsync(string verb, IDictionary<string, object?>? args, IDictionary<string, object?>? providerOptions = null, CancellationToken cancellationToken = default)`
  — the raw call.
- `MediaResult(IReadOnlyList<MediaFile> Files, string Status, string? Text = null, string? JobId = null)` ·
  `MediaFile(Type, MimeType, Url)` (`.ToPart()` → `ContentPart`).
- `media.Tools(): IReadOnlyList<ITool>` (source `"media"`), or `Toolkit.Options.Media` / `.WithMedia(media)`.
- `RunResult.Files: IReadOnlyList<RunFile>` — `RunFile(Type, MimeType, Url, Data, From, CallId)`, in call
  order; the same parts are on `ToolCalls[i].Parts`.
- Errors: the function face throws `MediaException` (message is the exact §7G string); cancellation throws
  `OperationCanceledException`. A media tool never throws (`IsError`).
- Equivalents: `createMedia` (js) · `create_media` (py) · `CreateMedia` (go) · `Media.create` (java) ·
  `Toolnexus.Media.new` (elixir) · `toolnexus.media/create-media` (clojure) · `create_media` (rust).
