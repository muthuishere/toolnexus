Crate **`toolnexus`** (Rust edition 2024, async on tokio). See the
[combined API Reference](/toolnexus/api/) for every symbol shown in eight-language synced tabs.
Every runnable example in this section is compiled and executed in CI against the `rust/` port.

<Aside type="note">
The Rust port is held to conformance tier **full** (`conformance/options_manifest.json`), like the
other seven. It is published to crates.io as `toolnexus`.
Not done: a Gemini client
style (Gemini is a schema adapter, as in Go), and the Windows code paths compile but have not
been run. Cargo features: `mcp-http` (MCP over streamable HTTP) and `serve` (A2A / MCP server),
both on by default.
</Aside>

## Toolkit

- `create_toolkit(ToolkitOptions) -> Result<Toolkit, ToolkitError>` (async).
- `ToolkitOptions` fields: `mcp_config` (`McpConfigInput::Path | Json | Parsed`), `skills_dir`,
  `skills`, `skill_provider`, `skills_filter`, `skill_sample_limit`, `extra_tools`, `builtins`,
  `agents`, `disable_tools`, `disable_skills`, `wait_for`.
- `tk.tools()` · `get` · `execute` · `skills_prompt` · `mcp_status` · `register` · `add_agent` ·
  `serve` · `close`.

## Client

- `client::create_client(ClientOptions) -> Client` → `run`, `ask` (memory by id), `stream` /
  `stream_with_id` (an `mpsc::UnboundedReceiver<StreamEvent>`), `run_with_answer` /
  `ask_with_answer` (durable resume), `list_models`, `translate`.
- `create_in_process_client(InProcessOptions)` for a model you run yourself; `acp_generate` /
  `acp_generate_stream` drive a local ACP coding agent as the model.

## Tools you build — native, HTTP, built-ins

- `define_tool(name, description, schema, f)` · `define_typed_tool::<T>(…)` (serde args).
- `http::http_tool(HttpToolOptions { name, description, method, url, headers, query, body,
  input_schema, timeout_ms, result_mode })`.
- `BuiltinsConfig` → the ten built-ins plus opt-in `background`, `web_search`, `notebook_edit`;
  `BuiltinsConfig::off()` disables them.

## Media generation

Guide: [Media generation](/toolnexus/media/) · recipe: [Generate images, video and speech](/toolnexus/cookbook/media/) · SPEC §7G.

- `load_media_style(path: impl AsRef<Path>) -> Result<MediaStyle, MediaError>`
- `create_media(styles: impl Into<Vec<MediaStyle>>, opts: MediaOptions) -> Media` (also `Media::new`) — a verb
  resolves to the first style that declares it.
- `MediaOptions { on_progress: Option<OnProgressFn>, http_client: Option<reqwest::Client> }` —
  `OnProgressFn = Arc<dyn Fn(&MediaProgress) + Send + Sync>`, `MediaProgress { verb, job_id, status }`.
- Verbs, each `async fn x(&self, input: XInput) -> Result<MediaResult, MediaError>`:
  `image(ImageInput { prompt, width, height, aspect_ratio, seed, provider_options })` ·
  `video(VideoInput { prompt, image, seconds, aspect_ratio, provider_options })` ·
  `speech(SpeechInput { text, voice, provider_options })` · `transcribe(TranscribeInput { audio, provider_options })` ·
  `clone_voice(CloneVoiceInput { name, samples, provider_options })` ·
  `talking(TalkingInput { image, audio, provider_options })`. Optional fields are `Option<_>`; inputs derive
  `Default`.
- `generate(&self, verb: &str, args: Map<String, Value>)` · `generate_with(&self, verb, args, provider_options: Option<Map<String, Value>>, cancel: &CancellationToken)`
  — the raw call. Only `generate_with` takes a cancellation token.
- `MediaResult { files: Vec<MediaFile>, text: Option<String>, job_id: Option<String>, status }` ·
  `MediaFile { kind, mime_type, url }` (`kind` serialises as `type`).
- `media.tools() -> Vec<Tool>` (source `"media"`), or `ToolkitOptions.media`.
- `RunResult.files: Vec<RunFile>` — `{ kind, mime_type, url, data, from, call_id }`, in call order; the same
  parts are on `tool_calls[i].parts`.
- Errors: `MediaError::Message(String)` displays the exact §7G string; `MediaError::Cancelled` when the token
  fires. A media tool never errors (`ToolResult::error`, `is_error: true`).
- Equivalents: `createMedia` (js) · `create_media` (py) · `CreateMedia` (go) · `Media.create` (java) ·
  `Media.Create` (c#) · `Toolnexus.Media.new` (elixir) · `toolnexus.media/create-media` (clojure).
