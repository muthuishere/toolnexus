Opt-in hooks on an ACP model source: choose the permission option, watch every session/update, cancel a turn, and stream through an in-process client.

## What to use instead

Elixir ships `Toolnexus.Acp` (`elixir/lib/toolnexus/acp.ex`): `connect/2` spawns the agent over
stdio and keeps one warm session, `prompt/3` runs a turn, `close/1` stops it, and the source
plugs into the client through the in-process path. What it does **not** have yet is any of the
four Go hooks:

- **Permissions** — every `session/request_permission` is answered inline with the first
  `allow`-kind option. There is no host callback, so a plan mode or a human approval prompt
  cannot sit in front of the agent's own tool calls. If you need one, configure the agent
  itself (most ACP agents have their own permission mode) or gate the toolnexus tools the agent
  is given through `before_tool`.
- **Updates** — only `agent_message_chunk` text forms the reply; thought chunks, tool-call
  narration and plans are dropped, and there is no observer.
- **Cancel** — a turn cannot be cancelled with `session/cancel`; stop it with a `prompt/3`
  timeout, or `close/1` the session (which ends the agent process).
- **Streaming** — an ACP-backed client does not stream; use `Client.run/4`.

The Go API is documented at [`ACPOptions.OnPermission`](/api/go/client/acp-hooks/). Tracked in
`openspec/changes/add-go-host-asks`, task 2.6d.
