The unified client: system prompt, skills injection, parallel and chained tool calls, retries, memory.

## When to use it

To run the tool-calling loop against an OpenAI- or Anthropic-style endpoint: system prompt + skills catalog, concurrent tool calls, hooks, retries, memory, streaming.

## Why this and not the alternative

Use the client rather than your own loop: it implements §8 and §10 the same way as the other seven ports, including Retry-After, the API-key-by-host rule and suspension.

<Aside type="tip" title="When not to use it">
For a model you run in-process (or an ACP agent), use `create_in_process_client`.
</Aside>

## Examples

### 1. OpenRouter, key from the environment

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
```

### 2. Anthropic with a system prompt

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
let client = create_client(ClientOptions {
    base_url: "https://api.anthropic.com/v1".into(),
    style: Style::Anthropic,
    model: "claude-sonnet-4-5".into(),
    system_prompt: "Be terse.".into(),
    max_turns: 20,
    ..Default::default()
});
```

### 3. A local server needs an explicit key source

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
let client = create_client(ClientOptions {
    base_url: "http://localhost:11434/v1".into(),
    model: "llama3".into(),
    api_key_env: "LOCAL_LLM_KEY".into(),
    retries: 4,
    timeout_ms: 120_000,
    ..Default::default()
});
```
