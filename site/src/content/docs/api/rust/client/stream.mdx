The streaming loop: text deltas, tool-call events, and suspension events as they happen.

## When to use it

For a UI: text deltas, `tool_call` / `tool_result` events (with `via` for `call_tool` or ACP), a `pending` event on suspension, then `done` with the final `RunResult`, or `error`.

## Why this and not the alternative

Use `stream` instead of `run` when a person is watching; the loop is the same.

<Aside type="tip" title="When not to use it">
For a batch job, `run` is simpler — you only need the result.
</Aside>

## Examples

### 1. Print text as it arrives

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let mut rx = client.stream("Explain this repo", &tk)?;
while let Some(ev) = rx.recv().await { if ev.kind == "text" { print!("{}", ev.delta); } }
```

### 2. Show tool activity

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let mut rx = client.stream("Fix the failing test", &tk)?;
while let Some(ev) = rx.recv().await {
    match ev.kind.as_str() {
        "tool_call" => println!("-> {} {}", ev.name, ev.args),
        "tool_result" => println!("<- {} error={}", ev.name, ev.is_error),
        "pending" => println!("needs input: {:?}", ev.request),
        "done" => println!("done: {}", ev.result.unwrap().text),
        _ => {}
    }
}
```

### 3. Stream a remembered conversation

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let mut rx = client.stream_with_id("And now the tests?", &tk, "session-1")?;
while let Some(ev) = rx.recv().await { if ev.kind == "text" { print!("{}", ev.delta); } }
```
