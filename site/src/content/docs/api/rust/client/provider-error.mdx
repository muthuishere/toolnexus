```rust
pub struct ProviderError { pub status: u16, pub body: String, pub retry_after: String }
// returned as ClientError::Provider(ProviderError)
```

A non-2xx response from the model endpoint raises a typed provider error carrying the status code, a redacted+capped body, and the retry-after signal — never a bare unstructured exception.

## When to use it

When a run fails on the provider's side: match `ClientError::Provider` to get the HTTP status, the (redacted) body and any `Retry-After`.

## Why this and not the alternative

Match the typed error instead of parsing the message string; the body is already redacted of account identifiers.

<Aside type="tip" title="When not to use it">
Transport failures are `ClientError::Transport`, not this.
</Aside>

## Examples

### 1. Branch on the status

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::client::ClientError;
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
match client.run("hi", &tk).await {
    Err(ClientError::Provider(p)) if p.status == 402 => println!("top up credits"),
    Err(e) => println!("failed: {e}"),
    Ok(r) => println!("{}", r.text),
}
```

### 2. Respect Retry-After yourself

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::client::ClientError;
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
if let Err(ClientError::Provider(p)) = client.run("hi", &tk).await {
    println!("retry after {}s", p.retry_after);
}
```

### 3. Log the body

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::client::ClientError;
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
if let Err(ClientError::Provider(p)) = client.run("hi", &tk).await { eprintln!("{}: {}", p.status, p.body); }
```
