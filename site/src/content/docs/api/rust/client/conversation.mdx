Keep a transcript across turns so the model remembers what it already did.

## When to use it

For a chat inside one process: each `send` carries the transcript so far, so the model remembers what it did.

## Why this and not the alternative

Use `Conversation` when the history lives with your object; use `ask(prompt, tk, id)` with a `store` when it must survive restarts or be shared by id.

<Aside type="tip" title="When not to use it">
For an independent task, `run` keeps no state.
</Aside>

## Examples

### 1. Two turns

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let mut chat = client.conversation(&tk);
chat.send("My name is Ada").await?;
let r = chat.send("What is my name?").await?;
```

### 2. Inspect the transcript

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let mut chat = client.conversation(&tk);
chat.send("hi").await?;
println!("{} messages", chat.messages.len());
```

### 3. Reset

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let mut chat = client.conversation(&tk);
chat.send("remember 7").await?;
chat.messages.clear();
```
