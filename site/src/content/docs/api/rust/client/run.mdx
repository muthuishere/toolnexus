pub async fn run(&self, prompt: impl Into<Prompt>, tk: &Toolkit) -> Result<RunResult, ClientError>

Send a prompt, let the loop call tools until the model stops, get a RunResult.

## When to use it

For one task: send the prompt, let the loop call tools until the model stops (or `max_turns`), and get `RunResult \{ text, tool_calls, turns, usage, status, pending \}`.

## Why this and not the alternative

Use `run` for a one-shot; use `ask(prompt, tk, id)` or `conversation(tk)` when the next prompt must remember this one.

<Aside type="tip" title="When not to use it">
When you need tokens as they arrive, use `stream`.
</Aside>

## Examples

### 1. One task

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let r = client.run("List the files here", &tk).await?;
println!("{} ({} turns)", r.text, r.turns);
```

### 2. Inspect tool calls

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let r = client.run("Read README.md", &tk).await?;
for c in &r.tool_calls { println!("{} -> error={}", c.name, c.is_error); }
```

### 3. Handle a suspension

```rust
use toolnexus::client::{ClientOptions, Style, create_client};
use toolnexus::{ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let client = create_client(ClientOptions {
    base_url: "https://openrouter.ai/api/v1".into(),
    style: Style::OpenAI,
    model: "openai/gpt-4o-mini".into(),
    ..Default::default()
});
let r = client.run("Ask me which environment, then deploy", &tk).await?;
if r.status == "pending" { println!("waiting on: {}", r.pending.unwrap().prompt); }
```
