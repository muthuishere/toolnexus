Intercept before/after model calls and tool calls: audit, redact, veto, or rewrite.

## When to use it

To audit, redact, veto or rewrite: `before_tool` sees the name, args, call id and `hints` and can replace the args or short-circuit with a result (or a `pending` for approval); `before_llm` can swap messages, tools or the model.

## Why this and not the alternative

Gate permissions in `before_tool` using `hints` rather than wrapping each tool: one hook covers MCP, builtins and your own tools alike.

<Aside type="tip" title="When not to use it">
Hooks are async and run on the loop's path; keep them fast, and return `Ok(None)` to change nothing.
</Aside>

## Examples

### 1. Log every tool call

```rust
use std::sync::Arc;
use toolnexus::client::{ClientOptions, Hooks, create_client};
let client = create_client(ClientOptions {
    hooks: Hooks {
        before_tool: Some(Arc::new(|ev| Box::pin(async move { println!("{} {}", ev.name, ev.args); Ok(None) }))),
        ..Default::default()
    },
    ..Default::default()
});
```

### 2. Deny anything that is not read-only

```rust
use std::sync::Arc;
use toolnexus::ToolResult;
use toolnexus::client::{Hooks, ToolOverride};
let hooks = Hooks {
    before_tool: Some(Arc::new(|ev| Box::pin(async move {
        if ev.hints.map(|h| h.read_only).unwrap_or(false) { return Ok(None); }
        Ok(Some(ToolOverride { result: Some(ToolResult::error(format!("{} needs approval", ev.name))), ..Default::default() }))
    }))),
    ..Default::default()
};
```

### 3. Redact tool output before the model sees it

```rust
use std::sync::Arc;
use toolnexus::client::{Hooks, ToolOverride};
let hooks = Hooks {
    after_tool: Some(Arc::new(|ev| Box::pin(async move {
        let mut r = ev.result.clone();
        r.output = r.output.replace("SECRET", "[redacted]");
        Ok(Some(ToolOverride { result: Some(r), ..Default::default() }))
    }))),
    ..Default::default()
};
```
