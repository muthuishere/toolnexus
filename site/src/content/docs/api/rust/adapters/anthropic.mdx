Render the toolkit as Anthropic tool-use schema.

## When to use it

When you call the provider yourself and need the tool schema in its shape: `\{name, description, input_schema\}`. Schema only — the input schema is passed through verbatim.

## Why this and not the alternative

Use the adapter rather than hand-writing the JSON: names and schemas then always match what `Toolkit::execute` routes.

<Aside type="tip" title="When not to use it">
If you use the toolnexus client, you never call this; the loop does.
</Aside>

## Examples

### 1. From a toolkit

```rust
use toolnexus::{BuiltinsConfig, ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions {
    builtins: Some(BuiltinsConfig::off()),
    ..Default::default()
}).await?;
let schema = tk.to_anthropic();
```

### 2. From a vector of tools

```rust
use toolnexus::{define_tool, to_anthropic};
let t = define_tool("now", "Current time", None, |_a, _c| async { Ok::<_, String>("12:00".to_string()) });
println!("{}", serde_json::to_string_pretty(&to_anthropic(&[t]))?);
```

### 3. Into a request body

```rust
use serde_json::json;
use toolnexus::{BuiltinsConfig, ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions {
    builtins: Some(BuiltinsConfig::off()),
    ..Default::default()
}).await?;
let body = json!({"model": "m", "tools": tk.to_anthropic()});
```
