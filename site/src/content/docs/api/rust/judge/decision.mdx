    pub model: String,
    pub answers: BTreeMap<String, DecisionAnswer>, // Noul | Choice | Score

impl Decision {
    pub fn noul(&self, key: &str) -> Result<&NoulAnswer, ClassifierError>;
    pub fn choice(&self, key: &str) -> Result<&ChoiceAnswer, ClassifierError>;
    pub fn score(&self, key: &str) -> Result<&ScoreAnswer, ClassifierError>;
}

One answer per question under the caller's own keys, read through typed accessors that fail loudly rather than hand back a zero.

## What to know

- A wrong-type or absent read is an `Err`, never a panic and never a default.
- `ChoiceAnswer.near_uniform` is DERIVED on decode: `max |p - 1/n| <= 0.05` over the map as
  returned. It flags an encoding that gave the model nothing to rank on; it is advisory.
- `ScoreAnswer::levels()` returns the legend in level order (`"2"` before `"10"`).
- `calibrated` is `false` for the `Llm` style. A threshold tuned on one backend does not transfer.

<Aside type="tip" title="Bands">
`toolnexus::judge::ask` wraps each answer in a `JudgeAnswer` with a `band` (`yes` / `no` /
`uncertain`, default cuts 0.30 / 0.70, exclusive on the confident side) and `sure`.
</Aside>

## Example

```rust
let d = c.evaluate(state, &qs).await?;
let dept = d.choice("department")?;
if !dept.near_uniform && dept.confidence > 0.7 {
    route_to(&dept.choice);
}
```
