```rust
pub fn create_builtin_tools(cfg: &BuiltinsConfig) -> Vec<Tool>
```

Construct every built-in tool directly, outside a toolkit.

## When to use it

When you want every builtin regardless of the toggles — for example to list their schemas in a UI — with the host boundary from `cfg` applied.

## Why this and not the alternative

Prefer `select_builtins` for a running agent: this one ignores `enabled` / `tools` and skips the shell check.

<Aside type="tip" title="When not to use it">
Do not use it to build an agent's toolset; the toggles exist for locked-down hosts.
</Aside>

## Examples

### 1. List names

```rust
use toolnexus::BuiltinsConfig;
use toolnexus::builtins::create_builtin_tools;
for t in create_builtin_tools(&BuiltinsConfig::default()) { println!("{}", t.name); }
```

### 2. Show hints

```rust
use toolnexus::BuiltinsConfig;
use toolnexus::builtins::create_builtin_tools;
for t in create_builtin_tools(&BuiltinsConfig::default()) { println!("{} {:?}", t.name, t.hints); }
```

### 3. Opt-in background shells

```rust
use std::sync::Arc;
use toolnexus::BuiltinsConfig;
use toolnexus::builtins::{BackgroundShells, create_builtin_tools};
let bg = Arc::new(BackgroundShells::default());
let tools = create_builtin_tools(&BuiltinsConfig { background: Some(bg.clone()), ..Default::default() });
// ... on shutdown:
bg.close_all().await;
```
