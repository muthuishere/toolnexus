```rust
pub fn select_builtins(cfg: &BuiltinsConfig) -> Result<Vec<Tool>, String>
```

Pick which built-in file/shell/web tools are in play, by name or by source toggle.

## When to use it

To get exactly the builtins a `BuiltinsConfig` enables (global toggle, then the per-tool map) — what `create_toolkit` uses. It fails when `bash` is enabled and no shell resolves.

## Why this and not the alternative

Use this rather than filtering `create_builtin_tools` yourself: it applies the whole-source-off short-circuit and the shell check exactly as §4 says.

<Aside type="tip" title="When not to use it">
Inside a toolkit, set `ToolkitOptions.builtins` instead.
</Aside>

## Examples

### 1. Everything on

```rust
use toolnexus::{BuiltinsConfig, select_builtins};
let tools = select_builtins(&BuiltinsConfig::default())?;
assert_eq!(tools.len(), 10);
```

### 2. Drop bash and write

```rust
use std::collections::BTreeMap;
use toolnexus::{BuiltinsConfig, select_builtins};
let tools = select_builtins(&BuiltinsConfig {
    tools: BTreeMap::from([("bash".to_string(), false), ("write".to_string(), false)]),
    ..Default::default()
})?;
```

### 3. Confined to a workspace

```rust
use toolnexus::{BuiltinsConfig, select_builtins};
let tools = select_builtins(&BuiltinsConfig {
    base_dir: "/work/project".into(), confine_to_base_dir: true, kill_grace_ms: 200,
    ..Default::default()
})?;
```
