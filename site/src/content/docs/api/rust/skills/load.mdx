Glob a skills directory and expose one skill tool with progressive disclosure.

## When to use it

For the common case: glob `**/SKILL.md` under one or more roots and get the `skill` tool plus `prompt()`, byte-identical to every other port.

## Why this and not the alternative

Use this shorthand when you have only directories; reach for `load_skills_with` for data skills, an allowlist or a sample cap.

<Aside type="tip" title="When not to use it">
Inside an agent, prefer `ToolkitOptions.skills_dir` so the toolkit adds the catalog and tool for you.
</Aside>

## Examples

### 1. One root

```rust
use toolnexus::skills::load_skills;
let src = load_skills(&["skills"]);
println!("{}", src.prompt());
```

### 2. Several roots, first name wins

```rust
use toolnexus::skills::load_skills;
let src = load_skills(&["project/skills", "/home/me/.skills"]);
println!("{:?}", src.skills.keys().collect::<Vec<_>>());
```

### 3. Run the skill tool

```rust
use serde_json::json;
use toolnexus::ToolContext;
use toolnexus::skills::load_skills;
let src = load_skills(&["skills"]);
let r = src.tool.call(json!({"name": "hello-world"}), ToolContext::default()).await;
println!("{}", r.output);
```
