```rust
pub struct SkillInventory { pub skills: Vec<SkillInfo>, pub skipped: Vec<SkillSkip> }
```

Enumerate discovered skills and, crucially, the ones that were skipped and why.

## When to use it

To show what was found and why something was skipped (missing name, malformed frontmatter, duplicate, unreadable) — for a settings screen or a lint step — without building a tool.

## Why this and not the alternative

Use this rather than `load_skills_with(..).skipped` when you do not want the tool or the filter applied: it is the unfiltered inventory.

<Aside type="tip" title="When not to use it">
To actually expose skills to a model, load them; this only lists.
</Aside>

## Examples

### 1. List names

```rust
use toolnexus::skills::{LoadSkillsOptions, list_skills};
let inv = list_skills(&LoadSkillsOptions { dirs: vec!["skills".into()], ..Default::default() });
for s in &inv.skills { println!("{}: {}", s.name, s.description); }
```

### 2. Report skips

```rust
use toolnexus::skills::{LoadSkillsOptions, list_skills};
let inv = list_skills(&LoadSkillsOptions { dirs: vec!["skills".into()], ..Default::default() });
for s in &inv.skipped { println!("{} {} {}", s.location, s.reason.as_str(), s.detail); }
```

### 3. Fail a CI lint on any skip

```rust
use toolnexus::skills::{LoadSkillsOptions, list_skills};
let inv = list_skills(&LoadSkillsOptions { dirs: vec!["skills".into()], ..Default::default() });
assert!(inv.skipped.is_empty(), "{:?}", inv.skipped);
```
