Read an mcp.json, connect every local stdio and remote streamable-HTTP server, expose each server tool as a Tool.

## When to use it

When you want MCP tools without a toolkit, or want to load servers yourself and hand the tools to `extra_tools`. It connects every enabled server concurrently and never fails as a whole.

## Why this and not the alternative

Prefer `create_toolkit` with `mcp_config` in most programs: it calls this for you and closes the connections with the toolkit.

<Aside type="tip" title="When not to use it">
If you need each server's tools as soon as it is ready, use `load_mcp_with` and its `on_server` callback.
</Aside>

## Examples

### 1. Load from a file

```rust
use toolnexus::mcp::{load_mcp, parse_mcp_config_file};
let cfg = parse_mcp_config_file("mcp.json")?;
let src = load_mcp(&cfg).await;
for t in &src.tools { println!("{}", t.name); }
src.close().await;
```

### 2. Check per-server status

```rust
use toolnexus::mcp::{load_mcp, parse_mcp_config_str};
let cfg = parse_mcp_config_str(r#"{"mcpServers":{"x":{"command":"missing-binary"}}}"#)?;
let src = load_mcp(&cfg).await;
println!("{} {:?}", src.status["x"].as_str(), src.errors.get("x"));
```

### 3. Hand the tools to a toolkit

```rust
use toolnexus::mcp::{load_mcp, parse_mcp_config_file};
use toolnexus::{ToolkitOptions, create_toolkit};
let src = load_mcp(&parse_mcp_config_file("mcp.json")?).await;
let tk = create_toolkit(ToolkitOptions { extra_tools: src.tools.clone(), ..Default::default() }).await?;
```
