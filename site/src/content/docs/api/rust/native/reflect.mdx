```rust
pub fn define_typed_tool<T, F, Fut, E>(name, description, schema: Value, f: F) -> Tool
where T: DeserializeOwned, F: Fn(T, ToolContext) -> Fut, Fut: Future<Output = Result<String, E>>
```

Derive the schema from the function signature or annotation instead of writing it by hand.

## When to use it

When your tool's arguments map onto a Rust struct: they are decoded with serde before your function runs, and a decode failure is an `isError` result naming the problem.

## Why this and not the alternative

Rust has no runtime reflection, so the schema is passed explicitly and advertised verbatim; the struct gives you typed access instead of indexing a `Value`.

<Aside type="tip" title="When not to use it">
For ad-hoc or loosely typed arguments, `define_tool` with a `Value` is simpler.
</Aside>

## Examples

### 1. A typed tool

```rust
use serde::Deserialize;
use serde_json::json;
use toolnexus::define_typed_tool;
#[derive(Deserialize)] struct Mul { a: f64, b: f64 }
let t = define_typed_tool("multiply", "Multiply", json!({"type":"object","properties":{"a":{"type":"number"},"b":{"type":"number"}},"required":["a","b"]}),
    |m: Mul, _c| async move { Ok::<_, String>((m.a * m.b).to_string()) });
```

### 2. Optional fields

```rust
use serde::Deserialize;
use serde_json::json;
use toolnexus::define_typed_tool;
#[derive(Deserialize)] struct Q { q: String, #[serde(default)] limit: Option<u32> }
let t = define_typed_tool("search", "Search", json!({"type":"object","properties":{"q":{"type":"string"},"limit":{"type":"number"}},"required":["q"]}),
    |a: Q, _c| async move { Ok::<_, String>(format!("{} (limit {})", a.q, a.limit.unwrap_or(10))) });
```

### 3. A decode failure

```rust
use serde::Deserialize;
use serde_json::json;
use toolnexus::{ToolContext, define_typed_tool};
#[derive(Deserialize)] struct N { n: i64 }
let t = define_typed_tool("sq", "", json!({"type":"object"}), |x: N, _c| async move { Ok::<_, String>((x.n * x.n).to_string()) });
let r = t.call(json!({"n": "x"}), ToolContext::default()).await;
assert!(r.is_error && r.output.starts_with("invalid arguments"));
```
