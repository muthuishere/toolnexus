Sweep a module or class and collect every function marked as a tool.

## What to use instead

Build a `Vec<Tool>` with `define_tool` / `define_typed_tool` and pass it as `extra_tools`.

## See also

- [`define_tool`](/api/rust/native/define-tool/) — Wrap a plain function with a name, description and schema — the shortest path from code you have to a tool the LLM can call.
- [`define_typed_tool`](/api/rust/native/reflect/) — Derive the schema from the function signature or annotation instead of writing it by hand.
