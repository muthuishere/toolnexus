```rust
pub fn memory_tool(dir: impl AsRef<Path>) -> Tool   // toolnexus::agents
// input: { action: "add" | "replace" | "remove", target?: "self" | "user", text: string, with?: string }
```

One tool, three actions, over `MEMORY.md` (`target: "self"`, default) or `USER.md`
(`target: "user"`). Every write goes to disk and loads at the START of the next session — it never
changes the live prompt, so a long-lived persona stays cache-stable. A replace/remove of a
substring that is not there is a loud `isError` and the file is unchanged. Not one of the default
builtins: it exists for a home-wired persona.

## Example

```rust
let tool = toolnexus::agents::memory_tool("./ava");
let r = tool.call(serde_json::json!({"action": "add", "text": "Likes hiking"}), Default::default()).await;
// r.output == "ok (add → MEMORY.md); loads next session"
```
