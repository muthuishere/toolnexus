```rust
pub fn from_dir(dir: impl AsRef<Path>, opts: FromDirOptions) -> Agent   // toolnexus::agents
pub struct FromDirOptions { pub does: String, pub name: String, pub model: String,
                            pub tools: Vec<Tool>, pub memory: Option<bool> }
pub fn start_agent(a: &Agent, opts: StartOptions) -> Result<StartedAgent, String>
pub struct StartOptions { pub options: Options, pub every_ms: u64, pub on_beat: Option<OnBeatFn> }
```

The directory IS the agent: `from_dir` composes the soul from the bootstrap files and wires the
`memory` tool over the same directory (`memory: Some(false)` omits it). The name defaults to the
directory's base name, the model to `"inherit"`. `start_agent` gives the persona a heartbeat: each
interval it posts a tick to the agent's own inbox (ticks coalesce) and, when idle, wakes it with
"read HEARTBEAT.md and act, else reply HEARTBEAT_OK"; a `HEARTBEAT_OK` reply stays silent. All
timing goes through the runtime `Clock`. Inbound channels are the host's job (`post` / `wake`).

## Example

```rust
use toolnexus::agents::{FromDirOptions, Options, StartOptions, from_dir, start_agent};
let ava = from_dir("./ava", FromDirOptions::default());
let (r, _) = ava.run(Options { in_process: Some(model.clone()), ..Default::default() }, "who are you?").await;
let hb = start_agent(&ava, StartOptions { options: Options { in_process: Some(model), ..Default::default() },
                                          every_ms: 60_000, ..Default::default() })?;
// … hb.beats() collects substantive beats; hb.stop().await tears it down
```
