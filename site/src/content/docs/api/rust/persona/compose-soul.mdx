```rust
pub fn compose_soul(dir: impl AsRef<Path>) -> (String, Vec<String>)   // toolnexus::agents
pub const BOOTSTRAP_ORDER: [&str; 7] =
    ["AGENTS.md", "SOUL.md", "IDENTITY.md", "USER.md", "TOOLS.md", "HEARTBEAT.md", "MEMORY.md"];
```

Reads the bootstrap files present under `dir`, in canonical order, each capped at 2 MB (an
over-cap file is truncated with a notice; the file on disk is untouched), and joins them as
`## <file>` sections. Returns the soul and the files found. Composed once, at session start: the
soul is a frozen snapshot for the run.

## Example

```rust
let (soul, found) = toolnexus::agents::compose_soul("./ava");
// found == ["SOUL.md", "USER.md", "HEARTBEAT.md", "MEMORY.md"]
```
