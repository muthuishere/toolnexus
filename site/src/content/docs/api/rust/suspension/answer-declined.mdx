```rust
pub fn answer_declined(id: impl Into<String>, reason: &str) -> Answer   // toolnexus::relay
```

The Answer for a refused request: `ok: false` and a reason (`""` ⇒ `"declined"`). A declined relay
is an error tool result, not an aborted run — the model sees the refusal and recovers. Through the
MCP elicitation bridge, `reason: "declined"` maps to `decline` (anything else to `cancel`).

## Example

```rust
use toolnexus::relay::answer_declined;
let wait_for: toolnexus::client::WaitForFn = std::sync::Arc::new(|req| Box::pin(async move {
    Ok(answer_declined(req.id, "not today"))
}));
```
