```rust
pub fn answer_output(id: impl Into<String>, output: impl Into<String>) -> Answer   // toolnexus::relay
```

The Answer for a single outstanding call: `{ id, ok: true, data: { "output": <output> } }` — the
one key the engine reads for a relay result and for a durable resume. For several relayed calls,
or to mark the host's tool as failed, use `relay_answer(id, &[RelayResult { .. }])`.

## Example

```rust
use toolnexus::relay::answer_output;
let res = client.run_with_answer(Default::default(), &tk, halted.messages, &req, &answer_output(&req.id, "us-east-1")).await?;
```
