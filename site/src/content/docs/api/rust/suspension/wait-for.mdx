The single hook where the host resolves a suspension — in-process prompt or durable queue, same contract.

## When to use it

The host slot that resolves a suspension inline: show the request to a person, return an `Answer`. `wait_for_ctx` also gets the turn's cancellation, so a pending question ends with its turn; it wins when both are set.

## Why this and not the alternative

Set `wait_for` when someone is present to answer now; leave it unset to let `run` return `status: "pending"` and resume later.

<Aside type="tip" title="When not to use it">
An `Answer \{ ok: false \}` is fed back as an error result, not retried.
</Aside>

## Examples

### 1. Approve everything (tests)

```rust
use std::sync::Arc;
use toolnexus::Answer;
use toolnexus::client::{ClientOptions, WaitForFn, create_client};
let wf: WaitForFn = Arc::new(|req| Box::pin(async move { Ok(Answer { id: req.id, ok: true, ..Default::default() }) }));
let client = create_client(ClientOptions { wait_for: Some(wf), ..Default::default() });
```

### 2. Ask on the terminal

```rust
use std::sync::Arc;
use toolnexus::Answer;
use toolnexus::client::WaitForFn;
let wf: WaitForFn = Arc::new(|req| Box::pin(async move {
    println!("{}", req.prompt);
    let mut line = String::new();
    std::io::stdin().read_line(&mut line).map_err(|e| e.to_string())?;
    Ok(Answer { id: req.id, ok: line.trim() == "y", ..Default::default() })
}));
```

### 3. Cancellable

```rust
use std::sync::Arc;
use toolnexus::Answer;
use toolnexus::client::{ClientOptions, WaitForCtxFn, create_client};
let wf: WaitForCtxFn = Arc::new(|cancel, req| Box::pin(async move {
    tokio::select! {
        _ = cancel.cancelled() => Err("turn cancelled".to_string()),
        _ = tokio::time::sleep(std::time::Duration::from_secs(1)) => Ok(Answer { id: req.id, ok: true, ..Default::default() }),
    }
}));
let client = create_client(ClientOptions { wait_for_ctx: Some(wf), ..Default::default() });
```
