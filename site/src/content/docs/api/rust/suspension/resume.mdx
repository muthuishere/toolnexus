<Aside type="caution" title="Not available in Rust">
Agent-runtime resume is not ported to Rust; a halted run is continued by calling `ask` again on the same conversation id. Tracked in `openspec/changes/add-rust-port`.
</Aside>

Route an Answer to the deepest suspended sub-agent handle and resume it in place.

## What to use instead

Answer out of band, then `client.ask(prompt, tk, id)`.
