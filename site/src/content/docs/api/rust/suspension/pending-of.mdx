```rust
pub fn pending_of(result: &ToolResult) -> Option<Request>
```

Detect that a RunResult is parked rather than finished, and get the Request that parked it.

## When to use it

To tell whether a result is a suspension (and read its request) — in a hook, a test, or a loop of your own.

## Why this and not the alternative

Use this rather than reading `metadata["pending"]` yourself; it decodes the typed `Request`.

<Aside type="tip" title="When not to use it">
With the client, `RunResult.pending` already carries the request.
</Aside>

## Examples

### 1. Check a result

```rust
use toolnexus::{ToolResult, auth_required, pending_of};
assert!(pending_of(&ToolResult::ok("x")).is_none());
assert_eq!(pending_of(&auth_required("https://x", "")).unwrap().kind, "authorization");
```

### 2. In an after_tool hook

```rust
use std::sync::Arc;
use toolnexus::client::Hooks;
use toolnexus::pending_of;
let hooks = Hooks {
    after_tool: Some(Arc::new(|ev| Box::pin(async move {
        if let Some(r) = pending_of(&ev.result) { println!("{} suspended: {}", ev.name, r.prompt); }
        Ok(None)
    }))),
    ..Default::default()
};
```

### 3. Your own loop

```rust
use serde_json::json;
use toolnexus::{BuiltinsConfig, ToolContext, ToolkitOptions, create_toolkit, pending_of};
let tk = create_toolkit(ToolkitOptions::default()).await?;
let r = tk.execute("question", json!({"questions":[{"question":"Name?"}]}), ToolContext::default()).await;
if let Some(req) = pending_of(&r) { println!("ask: {}", req.prompt); }
```
