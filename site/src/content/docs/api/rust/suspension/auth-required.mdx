```rust
pub fn auth_required(url: &str, prompt: &str) -> ToolResult
```

The auth-shaped suspension: hand back a URL, resume once the user has granted access.

## When to use it

When a tool needs the user to authorize at a URL: an `authorization` suspension whose output is the prompt plus the URL. An empty prompt uses the shared default text.

## Why this and not the alternative

Use this rather than `pending` by hand so the kind and default prompt match every other port.

<Aside type="tip" title="When not to use it">
For a yes/no or a typed value, use `pending` with `approval` / `input`.
</Aside>

## Examples

### 1. Default prompt

```rust
use toolnexus::auth_required;
let r = auth_required("https://example.com/oauth", "");
assert_eq!(r.output, "Authorization required to continue\nhttps://example.com/oauth");
```

### 2. Custom prompt

```rust
use toolnexus::auth_required;
let r = auth_required("https://github.com/login/device", "Sign in to GitHub");
```

### 3. Inside a tool

```rust
use toolnexus::{Tool, ToolResult, ToolSource, auth_required, empty_schema};
use std::sync::Arc;
let t = Tool { name: "gh".into(), description: "".into(), input_schema: empty_schema(), source: ToolSource::Custom, hints: None,
    execute: Arc::new(|_a, ctx| Box::pin(async move {
        if ctx.answer.is_some() { ToolResult::ok("authorized") } else { auth_required("https://example.com/auth", "") }
    })) };
```
