```rust
// toolnexus::agents — the §7D TaskResult.status set (seven values)
TASK_STATUS_DONE, TASK_STATUS_PENDING, TASK_STATUS_INCOMPLETE, TASK_STATUS_INTERRUPTED,
TASK_STATUS_CLOSED, TASK_STATUS_TIMEOUT, TASK_STATUS_ERROR
// TaskResult.limit — the closed stop vocabulary
LIMIT_MAX_TURNS, LIMIT_MAX_TOKENS, LIMIT_MAX_TOOL_CALLS, LIMIT_MAX_WALL_MS, LIMIT_MAX_CHILDREN,
LIMIT_MAX_CONCURRENT, LIMIT_MAX_DEPTH, LIMIT_COMPLETION, LIMIT_TIMEOUT
```

The strings a host branches on, identical in all ports. The §7D agent set is not the §8 client's
(`RunResult.status` is `done | pending | incomplete`): `"timeout"` belongs only to `wait(handle,
timeout)` — a wait deadline while the child keeps running. Every limit stop (`incomplete`,
`timeout`) names its limit; every other status leaves `limit` empty.

## Example

```rust
use toolnexus::agents::{LIMIT_MAX_TOKENS, TASK_STATUS_INCOMPLETE};
let r = rt.run_turn(&h, "again").await;
if r.status == TASK_STATUS_INCOMPLETE && r.limit == LIMIT_MAX_TOKENS { /* top up the budget */ }
```
