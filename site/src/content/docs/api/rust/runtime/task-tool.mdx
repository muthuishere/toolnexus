```rust
// Not constructed by hand: a Def with a non-empty `team` gets it on every turn.
// name: "task", input: { "agent": string, "prompt": string }
// description: "Delegate a subtask to an isolated subagent. Available agents — <name>: <does>; …"
```

The model-facing delegation surface. Only an agent that declares a `team` gets a `task` tool
(recursion is opt-in), and its targets are exactly that team — anything else is an error result
listing the team. Each call fuses spawn → wake → wait → close into a context-isolated child and
returns only the child's final text with `{agent, turns, totalTokens}` metadata. A suspending child
presents exactly as a suspending tool (the §10 Request, with `data.path` naming the leaf). On a
durable resume, a re-invoked task with the same (agent, prompt) REATTACHES to the existing child
instead of spawning a duplicate.

## Example

```rust
use toolnexus::agents::{self, Spec};
let explore = agents::new("explore", Spec { does: "read-only research".into(), ..Default::default() });
let coordinator = agents::new("coordinator", Spec {
    does: "splits and delegates".into(),
    team: vec![explore],   // ⇒ the coordinator's model sees a `task` tool
    ..Default::default()
});
```
