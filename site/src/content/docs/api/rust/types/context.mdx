Optional per-call context handed to execute: cancellation, identity, and host-supplied state.

## When to use it

Inside a tool's execute: honour `cancel` when the turn is cancelled, tell sibling calls apart with `call_id` (the loop runs one message's calls concurrently), and read `answer` when the loop re-runs you after a §10 suspension.

## Why this and not the alternative

Read cancellation from the context rather than a global flag: the loop creates one token per turn, so cancelling one turn never stops another.

<Aside type="tip" title="When not to use it">
Outside a loop, pass `ToolContext::default()` — every field is optional.
</Aside>

## Examples

### 1. Honour cancellation

```rust
use toolnexus::define_tool;
let slow = define_tool("slow", "Waits", None, |_a, ctx| async move {
    tokio::select! {
        _ = ctx.cancel.cancelled() => Err("cancelled".to_string()),
        _ = tokio::time::sleep(std::time::Duration::from_secs(5)) => Ok("done".to_string()),
    }
});
```

### 2. Use the call id

```rust
use toolnexus::define_tool;
let t = define_tool("who", "", None, |_a, ctx| async move {
    Ok::<_, String>(ctx.call_id.unwrap_or_else(|| "direct".into()))
});
```

### 3. Read a §10 answer

```rust
use std::sync::Arc;
use toolnexus::{Request, Tool, ToolResult, ToolSource, empty_schema, pending};
// A suspension must be the tool's whole ToolResult (it carries metadata.pending),
// so build the Tool directly rather than through define_tool, whose Ok(String) has no metadata.
let ask = Tool {
    name: "confirm".into(), description: "Ask first".into(), input_schema: empty_schema(),
    source: ToolSource::Custom, hints: None,
    execute: Arc::new(|_a, ctx| Box::pin(async move {
        match ctx.answer {
            Some(a) if a.ok => ToolResult::ok("confirmed"),
            Some(_) => ToolResult::error("declined"),
            None => pending(Request { kind: "approval".into(), prompt: "Proceed?".into(), ..Default::default() }),
        }
    })),
};
```
