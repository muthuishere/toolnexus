```rust
pub struct Tool {
    pub name: String,
    pub description: String,
    pub input_schema: Value,
    pub source: ToolSource,
    pub execute: ExecuteFn,
    pub hints: Option<ToolHints>,
}
```

The uniform shape every tool source collapses to: name, description, JSON-Schema parameters, execute.

## When to use it

When you need to hold, inspect, wrap or build a tool by hand: every source (MCP, skill, builtin, native, http) produces this one struct, so a toolkit, the adapters and the client loop treat them identically.

## Why this and not the alternative

Build one with `define_tool` / `define_typed_tool` / `http_tool` rather than a struct literal: they fill `source`, the default schema and the error mapping for you.

<Aside type="tip" title="When not to use it">
If you only want to expose a function, use `define_tool`; a raw `Tool` literal is for wrapping an existing tool (for example adding a guard around `execute`).
</Aside>

## Examples

### 1. Inspect a toolkit's tools

```rust
use toolnexus::{BuiltinsConfig, ToolkitOptions, create_toolkit};
let tk = create_toolkit(ToolkitOptions {
    builtins: Some(BuiltinsConfig::off()),
    ..Default::default()
}).await?;
for t in tk.tools() {
    println!("{} {:?} {}", t.name, t.source, t.description);
}
```

### 2. Call a tool directly

```rust
use serde_json::json;
use toolnexus::{ToolContext, define_tool};
let t = define_tool("ping", "Reply pong", None, |_a, _c| async { Ok::<_, String>("pong".to_string()) });
let r = t.call(json!({}), ToolContext::default()).await;
assert_eq!(r.output, "pong");
```

### 3. Wrap a tool's execute

```rust
use std::sync::Arc;
use toolnexus::{Tool, ToolResult};
fn read_only_guard(inner: Tool) -> Tool {
    let exec = inner.execute.clone();
    Tool {
        execute: Arc::new(move |args, ctx| {
            let exec = exec.clone();
            Box::pin(async move {
                if ctx.cancel.is_cancelled() { return ToolResult::error("cancelled"); }
                exec(args, ctx).await
            })
        }),
        ..inner
    }
}
```
