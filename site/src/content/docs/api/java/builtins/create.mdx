```java
public static List<Tool> create()
```

Builds all ten built-in tools — `bash`, `read`, `write`, `edit`, `grep`, `glob`, `webfetch`,
`question`, `apply_patch`, `todowrite`, in that fixed order — with no filtering and no config.
Each is source `"builtin"`, with the same name and `inputSchema` as opencode's built-ins, and
each obeys the uniform contract: a failure is `ToolResult{isError:true}`, never a thrown
exception across the tool boundary.

## When to use it

When you want the raw, complete built-in set — every tool, unconditionally — to inspect, filter
yourself with custom logic, or register directly without going through a `Toolkit` or a config
object at all.

## Why this and not the alternative

<Aside type="tip" title="create is unconditional, select respects a config">
[`BuiltinTools.select(cfg)`](/api/java/builtins/select/) is `create()` plus the on/off and
per-name filtering a `Toolkit.Options.builtins` config expresses. Reach for `create()` directly
when there is no config to honor — you always want all ten — or when you are writing your own
filtering logic on top and don't want `select`'s particular rules getting in the way.
</Aside>

`Toolkit.create` with no `builtins` option set is effectively `create()` merged with every other
source — the ten built-ins ship on by default.

## Examples

### 1. All ten, in the documented fixed order

```java test
import io.github.muthuishere.toolnexus.*;
import java.util.List;

public class Example {
    public static void main(String[] args) {
        List<Tool> tools = BuiltinTools.create();

        List<String> expected = List.of(
            "bash", "read", "write", "edit", "grep", "glob",
            "webfetch", "question", "apply_patch", "todowrite"
        );
        List<String> names = tools.stream().map(Tool::name).toList();
        if (!names.equals(expected)) throw new AssertionError(names);

        for (Tool t : tools) {
            if (!t.source().equals("builtin")) throw new AssertionError(t.name() + " source");
        }

        System.out.println("ok: " + names);
    }
}
```

### 2. Calling `read` directly — a failure is a `ToolResult`, not a thrown exception

`read` is not text-only: a recognised media file (`png jpg jpeg gif webp pdf mp3 wav`) comes back
as a [`ContentPart`](/api/java/types/content-part/) on `ToolResult.parts`, with `output` describing
it. Anything else is read as UTF-8 text windowed by `offset`/`limit`, and bytes that are not valid
UTF-8 are an `isError` result — never a thrown exception.

```java test
import io.github.muthuishere.toolnexus.*;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.Map;

public class Example {
    static Tool find(List<Tool> tools, String name) {
        for (Tool t : tools) if (t.name().equals(name)) return t;
        throw new IllegalStateException("no such builtin: " + name);
    }

    public static void main(String[] args) throws Exception {
        Path tmp = Files.createTempFile("toolnexus-docs", ".txt");
        Files.writeString(tmp, "line one\nline two\nline three\n");

        Tool read = find(BuiltinTools.create(), "read");

        ToolResult ok = read.execute(Map.of("path", tmp.toString()), new ToolContext());
        if (ok.isError() || !ok.output().contains("line two")) throw new AssertionError(ok.output());

        // A missing file is a tool ERROR, not an exception.
        ToolResult missing = read.execute(Map.of("path", tmp.toString() + ".does-not-exist"), new ToolContext());
        if (!missing.isError()) throw new AssertionError("expected isError");

        System.out.println("ok: read " + ok.output().lines().count() + " lines, missing-file handled");
    }
}
```

### 3. Registering the raw set into a `Toolkit`, without going through `builtins(cfg)`

```java test
import io.github.muthuishere.toolnexus.*;

public class Example {
    public static void main(String[] args) {
        try (Toolkit tk = Toolkit.create(new Toolkit.Options())) {
            // builtins(...) was never set on Options — but create() gives the same ten tools
            // directly, useful when you want to register a hand-picked subset instead.
            for (Tool t : BuiltinTools.create()) {
                if (tk.get(t.name()) == null) tk.register(t);
            }

            if (tk.get("bash") == null) throw new AssertionError("bash missing");
            if (!tk.get("bash").source().equals("builtin")) throw new AssertionError("source");

            System.out.println("ok: " + tk.toOpenAI().size() + " tools registered");
        }
    }
}
```

## Fields

| Member | Type | What it is |
|---|---|---|
| `create()` | `List<Tool>` | All ten built-ins, fixed order, `source() == "builtin"` on each. |
| Failure contract | — | Every built-in returns `ToolResult{isError:true}` on failure — never throws across `execute`. |
| Paths | — | Resolve relative to the process working directory unless absolute. |
| `read` on media | — | A `png/jpg/jpeg/gif/webp/pdf/mp3/wav` file returns a content part; undecodable bytes return an `isError` result. |

## Opt-in builtins, grep context and truncation metadata

The default ten are unchanged. These keys of the builtins config add more:

| key | adds |
|---|---|
| `background` (a [`BackgroundShells`](/api/java/builtins/background-shells/)) | `run_in_background` on `bash`, plus `bash_output` and `kill_shell` |
| `webSearch` (a `WebSearch`) | `websearch` — numbered title / URL / snippet; the library ships no provider |
| `notebookEdit: true` | `notebook_edit` — replace / insert / delete an `.ipynb` cell by id or index |

`grep` takes `context`, `before` and `after`: match lines `path:N:text`, context lines
`path-N-text`, `--` between groups. A `read` window that stops early sets `truncated`,
`totalLines`, `nextOffset` in `metadata`; a `grep` cut by `limit` sets `truncated` and `total`. The
text output is unchanged. `edit`, `write` and `apply_patch` results carry `metadata.files` and a
unified `metadata.diff`.

```java test
import io.github.muthuishere.toolnexus.*;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.Map;

public class Example {
    public static void main(String[] args) throws Exception {
        Path dir = Files.createTempDirectory("tn-grep");
        Files.writeString(dir.resolve("f.txt"), "a\nHIT1\nb\nc\nHIT2\n");
        WebSearch search = (query, limit) -> List.of(new WebSearch.Result("Docs", "https://example.com", "toolnexus"));
        List<Tool> tools = BuiltinTools.create(Map.of("baseDir", dir.toString(), "webSearch", search, "notebookEdit", true));
        List<String> names = tools.stream().map(Tool::name).toList();
        if (!names.contains("websearch") || !names.contains("notebook_edit")) throw new AssertionError(names);

        Tool grep = tools.stream().filter(t -> t.name().equals("grep")).findFirst().orElseThrow();
        ToolResult r = grep.execute(Map.of("pattern", "HIT1", "context", 1), null);
        if (!r.output().equals("f.txt-1-a\nf.txt:2:HIT1\nf.txt-3-b")) throw new AssertionError(r.output());
        ToolResult cut = grep.execute(Map.of("pattern", "HIT", "limit", 1), null);
        if (!Boolean.TRUE.equals(cut.metadata().get("truncated"))) throw new AssertionError(cut.metadata());
        System.out.println("ok: total=" + cut.metadata().get("total"));
    }
}
```
