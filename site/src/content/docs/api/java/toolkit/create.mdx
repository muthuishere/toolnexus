Collapse MCP servers, skills, built-ins, A2A agents and your own functions into **one** tool list
behind a single `Toolkit`. It connects every enabled MCP server (in parallel, failures isolated),
globs and parses the skill directories, resolves the built-in file/shell/web tools, fetches each
configured A2A agent's card, and de-dupes everything by final tool name (first source wins) into
one `Map<String, Tool>` you can hand straight to `LlmClient.run`/`stream`, or adapt to any
provider's tool schema.

## When to use it

Call `Toolkit.create` once per agent configuration — wherever you'd otherwise wire MCP, skills,
built-ins and your own functions up separately. It is the toolkit's only constructor: every
option is optional, so `Toolkit.create(new Toolkit.Options())` alone still gives you a working
(empty, all-builtins-on) toolkit. `Toolkit` is `AutoCloseable` — closing it disconnects every
connected MCP client, so build it in a try-with-resources (or hold it for the process lifetime
and close it on shutdown).

## Why this and not the alternative

<Aside type="tip" title="Reach for the single-source constructor when Toolkit is one source too many">
`Toolkit.create` is worth it the moment you combine two or more of \{MCP, skills, built-ins, extra
tools, A2A agents\} — it does the aggregation, precedence (builtins are lowest-precedence; an
`extraTools` entry with the same name shadows a builtin) and dedupe for you. If MCP is the
*only* source you need, [`McpSource.load`](/api/java/mcp/load/) directly is lighter — you get the
`McpSource` itself (its `status()` map) without the toolkit wrapper. Same story for skills alone:
[`SkillSource.load`](/api/java/skills/load/) gives you just the `skill` tool. Reach for
`BuiltinTools.select`/`create` directly only if you want the built-ins with no toggle logic and no
other source at all.
</Aside>

## Examples

### 1. The smallest useful call — built-ins only, no MCP, no skills

```java test
import io.github.muthuishere.toolnexus.*;

public class Example {
    public static void main(String[] args) {
        try (Toolkit tk = Toolkit.create(new Toolkit.Options())) {
            // No mcpConfig / skillsDir set — builtins default to ON, so the ten
            // built-in tools (bash/read/write/edit/grep/glob/webfetch/question/
            // apply_patch/todowrite) are the whole list.
            if (tk.tools().isEmpty()) throw new AssertionError("expected the built-ins");
            if (tk.get("bash") == null) throw new AssertionError("expected the bash builtin");
            System.out.println("ok: " + tk.tools().size() + " tools, no MCP/skills configured");
        }
    }
}
```

### 2. The realistic case — skills from disk plus a hand-written tool, builtins off

```java test
import io.github.muthuishere.toolnexus.*;
import java.util.Map;

public class Example {
    public static void main(String[] args) {
        Tool add = NativeTool.of("add", "Add two numbers", null, args -> {
            Number a = (Number) args.get("a");
            Number b = (Number) args.get("b");
            return String.valueOf(a.intValue() + b.intValue());
        });

        try (Toolkit tk = Toolkit.create(new Toolkit.Options()
                .skillsDir("examples/skills")   // the shared cross-language fixture
                .extraTools(add)
                .builtins(false))) {

            if (tk.get("skill") == null) throw new AssertionError("expected the skill tool");
            if (tk.get("add") == null) throw new AssertionError("expected the custom tool");
            if (tk.get("bash") != null) throw new AssertionError("builtins(false) should drop bash");

            ToolResult r = tk.execute("add", Map.of("a", 2, "b", 3));
            System.out.println("ok: skillsPrompt has hello-world="
                    + tk.skillsPrompt().contains("hello-world") + ", add(2,3)=" + r.output());
        }
    }
}
```

### 3. The full surface — MCP, disableTools/disableSkills, and a per-agent skills filter together

```java test
import io.github.muthuishere.toolnexus.*;
import java.util.List;
import java.util.Map;

public class Example {
    public static void main(String[] args) {
        // A bare server map, every server disabled — hermetic: no process spawned, no network reached.
        Map<String, Object> mcpConfig = Map.of(
                "srv", Map.of("type", "remote", "url", "https://example.invalid/mcp", "enabled", false));

        try (Toolkit tk = Toolkit.create(new Toolkit.Options()
                .mcpConfig(mcpConfig)
                .builtins(false)
                .skills(List.of(
                        new SkillSource.SkillDef("keep", "Keep this one", "body"),
                        new SkillSource.SkillDef("drop", "Dropped via disableSkills", "body")))
                .disableSkills("drop")
                .disableTools("nonexistent_tool"))) {

            // MCP: config parsed, server disabled, no tools contributed — no network reached.
            if (!"disabled".equals(tk.mcpStatus().get("srv"))) throw new AssertionError(tk.mcpStatus());

            String prompt = tk.skillsPrompt();
            if (!prompt.contains("keep")) throw new AssertionError("expected \"keep\" in: " + prompt);
            if (prompt.contains("**drop**")) throw new AssertionError("disableSkills should drop it: " + prompt);

            System.out.println("ok: mcpStatus=" + tk.mcpStatus() + ", skills filtered as expected");
        }
    }
}
```
