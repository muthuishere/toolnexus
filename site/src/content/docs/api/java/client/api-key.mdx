```java
// LlmClient.Options
public String apiKey;     // the key itself; used as-is when set
public String apiKeyEnv;  // the NAME of an env var to read it from (never the value)
public Options apiKey(String v)
public Options apiKeyEnv(String v)
```

Which key the client sends, and to which host. The order is fixed:

1. `apiKey` set: only it is used.
2. Else `apiKeyEnv` set: the env var with that name.
3. Else ONLY the env var that belongs to the `baseUrl` host, and only over https:
   `https://api.openai.com` → `OPENAI_API_KEY`, `https://api.anthropic.com` → `ANTHROPIC_API_KEY`,
   `https://openrouter.ai` (and subdomains) → `OPENROUTER_API_KEY`.

Any other host (a local server, a proxy, a gateway), or plain http, with neither `apiKey` nor
`apiKeyEnv` fails the request with `No API key: set apiKey or apiKeyEnv …`. There is no
cross-provider fallback, and the value is never logged. The same rules apply to
[`LlmClient.listModels`](/api/java/client/list-models/).

<Aside type="caution" title="BREAKING in 0.22.0">
Before 0.22.0, a client with no `apiKey` took the first of `OPENROUTER_API_KEY`, `OPENAI_API_KEY`,
`ANTHROPIC_API_KEY` that was set and sent it to whatever `baseUrl` was configured. A host on a local
or custom `baseUrl` that relied on that fallback must now set `apiKey` or `apiKeyEnv`.
</Aside>

## When to use it

Set `apiKeyEnv` when the key lives in an env var whose name the library cannot infer from the
host: a self-hosted gateway, an Azure or LiteLLM proxy, a local llama.cpp/Ollama server that checks
a token. Set `apiKey` when the host already holds the key (a secret manager, a per-tenant key). Set
neither when `baseUrl` is one of the three public providers and its own env var is set.

## Why this and not the alternative

<Aside type="tip" title="apiKeyEnv rather than reading the env yourself">
`apiKey(System.getenv("MY_KEY"))` works, but it puts the value in a field your code can print or
serialize. `apiKeyEnv("MY_KEY")` keeps only the name in your options; the value is read at request
time. Use `apiKey` when the key does not come from the environment at all.
</Aside>

## Examples

### 1. The smallest useful call — a local server with an explicit key

```java test
import com.sun.net.httpserver.HttpServer;
import io.github.muthuishere.toolnexus.*;
import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.nio.charset.StandardCharsets;
import java.util.concurrent.atomic.AtomicReference;

public class Example {
    public static void main(String[] args) throws Exception {
        AtomicReference<String> auth = new AtomicReference<>();
        HttpServer server = HttpServer.create(new InetSocketAddress("127.0.0.1", 0), 0);
        server.createContext("/", ex -> {
            auth.set(ex.getRequestHeaders().getFirst("Authorization"));
            byte[] b = "{\"choices\":[{\"message\":{\"content\":\"ok\"}}]}".getBytes(StandardCharsets.UTF_8);
            ex.getResponseHeaders().add("Content-Type", "application/json");
            ex.sendResponseHeaders(200, b.length);
            try (OutputStream os = ex.getResponseBody()) { os.write(b); }
        });
        server.start();
        try (Toolkit tk = Toolkit.create(new Toolkit.Options().builtins(false))) {
            LlmClient client = LlmClient.create(new LlmClient.Options()
                    .baseUrl("http://127.0.0.1:" + server.getAddress().getPort())
                    .model("local-model")
                    .apiKey("YOUR_KEY_HERE")); // a local host needs apiKey or apiKeyEnv
            LlmClient.RunResult res = client.run("hi", tk);
            if (!"ok".equals(res.text)) throw new AssertionError(res.text);
            if (!"Bearer YOUR_KEY_HERE".equals(auth.get())) throw new AssertionError(auth.get());
            System.out.println("ok: sent the explicit key");
        } finally {
            server.stop(0);
        }
    }
}
```

### 2. The realistic case — no key for a custom host is an error, not a leak

Even with `OPENAI_API_KEY` set in the environment, a client pointed at a non-provider host does not
send it.

```java test
import io.github.muthuishere.toolnexus.*;

public class Example {
    public static void main(String[] args) throws Exception {
        try (Toolkit tk = Toolkit.create(new Toolkit.Options().builtins(false))) {
            LlmClient client = LlmClient.create(new LlmClient.Options()
                    .baseUrl("http://127.0.0.1:9")   // nothing listens; we never get that far
                    .model("m")
                    .retries(0));
            String msg = "";
            try {
                client.run("hi", tk);
            } catch (RuntimeException e) {
                msg = e.getMessage();
            }
            if (!msg.contains("No API key")) throw new AssertionError(msg);
            System.out.println("ok: " + msg.substring(0, msg.indexOf(':')));
        }
    }
}
```

### 3. The full surface — `apiKeyEnv` names the variable

`apiKeyEnv` wins over the host table. When the named variable is unset, the error names it, so the
fix is obvious.

```java test
import io.github.muthuishere.toolnexus.*;

public class Example {
    public static void main(String[] args) throws Exception {
        try (Toolkit tk = Toolkit.create(new Toolkit.Options().builtins(false))) {
            LlmClient client = LlmClient.create(new LlmClient.Options()
                    .baseUrl("https://llm-gateway.internal.example/v1")
                    .model("m")
                    .apiKeyEnv("TOOLNEXUS_DOCS_GATEWAY_KEY")   // read at request time, never logged
                    .retries(0));
            String msg = "";
            try {
                client.run("hi", tk);
            } catch (RuntimeException e) {
                msg = e.getMessage();
            }
            if (!msg.contains("TOOLNEXUS_DOCS_GATEWAY_KEY")) throw new AssertionError(msg);
            System.out.println("ok: error names the env var");
        }
    }
}
```
