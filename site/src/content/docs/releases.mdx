## 0.20.0 — 2026-09-22

<Aside type="caution" title="Contains a breaking change">
The [full changelog entry](https://github.com/muthuishere/toolnexus/blob/main/CHANGELOG.md#0200--2026-09-22) names the ports affected and what moves.
</Aside>

- The built-in tools no longer close over the host process. bash runs on native Windows, relative paths can be scoped to a directory, and a timeout actually kills the job.
- retryAfter on the typed provider error now means the same thing in all seven ports — the raw Retry-After header, verbatim.
- Java can now parse an mcp.json without connecting to anything.
- Four API-reference pages documented signatures that do not exist, and one documented the wrong rule.
- The API reference now has a coverage gate, and it blocks CI.

[Full changelog](https://github.com/muthuishere/toolnexus/blob/main/CHANGELOG.md#0200--2026-09-22) · [GitHub release](https://github.com/muthuishere/toolnexus/releases/tag/v0.20.0)

## 0.18.0 — 2026-09-21

<Aside type="caution" title="Contains a breaking change">
The [full changelog entry](https://github.com/muthuishere/toolnexus/blob/main/CHANGELOG.md#0180--2026-09-21) names the ports affected and what moves.
</Aside>

- Fixed — a classifier retry backoff no longer lets Node exit out from under it (javascript)
- Four quiet disagreements between the ports, closed
- The classifier's retry backoff is yours to set, in every port
- TypeSafe's own API is a documented way to run a Classifier — and two defects it exposed
- Typed decisions — a Classifier, in all seven ports
- Spec — a beforeTool hook can raise a suspension, and now the contract says so
- Fixed — a guardrail that is not a plain string is refused, loudly, in every port
- Fixed — Run/Ask accept a nil toolkit as "no tools" (golang)
- Docs — the coding-agent scenario no longer says the agent runtime hides the hooks

[Full changelog](https://github.com/muthuishere/toolnexus/blob/main/CHANGELOG.md#0180--2026-09-21) · [GitHub release](https://github.com/muthuishere/toolnexus/releases/tag/v0.18.0)
