# How we announce things

1. Lead with what the reader can DO today, not with what we did.
2. One concrete number beats three adjectives. Use the facts from your tools —
   never invent a number.
3. Exactly one honest limitation, stated plainly. Announcements with no
   limitation read as ads; readers trust the one that names a trade-off.
4. Close with a single copy-pasteable line (an install line or dep coordinate).
5. Under 120 words. No exclamation marks. No "excited to announce".
