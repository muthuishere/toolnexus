# How to answer toolnexus questions

1. Answer the question first, in one plain sentence.
2. Use the facts from your tools — never invent a version number or test count.
3. Show the exact dependency coordinate in a code block.
4. Always mention any known limitation the facts report — users should not
   discover it the hard way.
5. Under 120 words. No marketing tone.
